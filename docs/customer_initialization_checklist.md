# SagittaDB 客户环境初始化检查表

> 用于客户首次部署、试运行和正式上线前验收。实施人员应逐项确认并记录结果。

## 1. 基础环境

| 检查项 | 要求 | 结果 |
|---|---|---|
| 部署模式 | 已确认 Docker Compose 或 Kubernetes + Helm。 |  |
| 访问入口 | Web 入口使用 HTTPS 或客户内网可信入口。 |  |
| 端口暴露 | 仅暴露前端/API 入口；PostgreSQL、Redis、Flower、Prometheus、Grafana 不直接暴露公网。 |  |
| 域名与证书 | 域名、证书、反向代理和回源地址已配置。 |  |
| 时间同步 | 主机或 Kubernetes 节点已启用 NTP。 |  |

## 2. 安全配置

| 检查项 | 要求 | 结果 |
|---|---|---|
| `APP_ENV` | 生产环境为 `production`。 |  |
| `SECRET_KEY` | 已替换为 32 位以上随机值，并已纳入客户密钥保管流程。 |  |
| 数据库密码 | PostgreSQL、Redis、Grafana 等默认密码已替换。 |  |
| License 公钥 | `LICENSE_PUBLIC_KEY` 与授权服务私钥匹配。 |  |
| 部署指纹 | `LICENSE_DEPLOYMENT_ID` 已生成并固定，后续升级不再变更。 |  |
| 默认管理员 | 首次初始化后已修改默认管理员密码。 |  |

## 3. 组织与权限

| 检查项 | 要求 | 结果 |
|---|---|---|
| 用户来源 | 已确认本地用户、LDAP、OAuth/CAS 或混合模式。 |  |
| 内置角色 | `superadmin`、`dba`、`dba_group`、`developer` 已初始化。 |  |
| 用户组 | 已按客户组织结构创建用户组并维护负责人。 |  |
| 资源组 | 已按实例范围创建资源组。 |  |
| 权限最小化 | DBA、研发、安全审计和系统管理员权限已分离。 |  |
| 审批流 | SQL 工单、查询权限、归档审批流已配置并指定有效审批人。 |  |

## 4. 数据库接入

| 检查项 | 要求 | 结果 |
|---|---|---|
| 实例清单 | 已确认首批接入实例、库名、账号和网络连通性。 |  |
| 连接测试 | 每个正式实例连接测试通过。 |  |
| 数据库注册 | 已同步或手动注册数据库/Schema，并禁用不开放给普通用户的库。 |  |
| 资源范围 | 实例已绑定到正确资源组。 |  |
| 客户验证后交付引擎 | Oracle、MSSQL、Elasticsearch/OpenSearch、Doris 已完成客户同构环境连接、元数据、查询、工单边界和监控/活动采集验证后再进入交付范围。 |  |
| 待验证引擎 | Cassandra 已具备最小兼容层，但 DDL/DML 工单执行仍关闭；除非已完成单独立项和客户同构环境验证，否则不作为正式可交付引擎承诺。 |  |

## 5. 功能验收

| 检查项 | 要求 | 结果 |
|---|---|---|
| SQL 工单 | 提交、预检查、审批、执行、取消和详情审计均通过。 |  |
| 查询权限 | 申请、审批、授权生效、到期失效和撤销均通过。 |  |
| 在线查询 | 权限拒绝原因、最大行数、导出和查询历史均可用。 |  |
| 数据字典 | 表、字段、约束、索引和 DDL 展示正常。 |  |
| 数据脱敏 | 命中规则后查询结果脱敏，查询日志记录脱敏状态。 |  |
| 观测中心 | 指标采集、会话诊断、SQL 洞察和容量数据可用。 |  |
| 数据归档 | 估算、申请、审批、执行、暂停、继续、取消和批次日志均通过。 |  |
| 通知 | 审批、执行、归档和 License 续期提醒投递记录可追踪。 |  |
| License | 离线导入或在线激活成功；刷新、过期、冻结、吊销策略已演练。 |  |
