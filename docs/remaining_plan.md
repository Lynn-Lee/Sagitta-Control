# SagittaDB 最新剩余计划任务

> 更新时间：2026-05-05  
> 适用范围：v1.0-GA 商业交付线 + v2-lite 授权体系 + License v2 在线激活/部署指纹绑定。

本文是当前剩余研发、验证和交付任务的统一入口。产品主链路、v2-lite 授权、License 客户侧能力、多引擎最小可用实现、数据库引擎兼容层本地研发、用户手册截图、预检脚本和 GA 验收脚本已进入交付收口状态；后续任务以真实环境验证、发布闸门、性能基线和交付自动化为主。

## P0 发布闸门

这些任务完成后，才建议生成客户正式交付包并进入生产上线窗口。

| 任务 | 交付物 | 验收口径 |
|---|---|---|
| 全量 CI 与安全流水线确认 | GitHub Actions 记录，包含后端、前端、Docker 构建、Bandit、pip-audit、Trivy、CodeQL。 | `release/1.0` 和目标版本标签流水线全部通过，失败项均有修复记录。 |
| 客户同构环境 GA 验收 | `deploy/preflight-check.sh` 与 `scripts/ga-acceptance-check.py` 执行记录。 | 至少一个正式支持引擎实例完成登录、权限、实例、数据字典、SQL 工单、查询权限、在线查询、归档、通知和 License 检查。 |
| 升级回滚演练 | 填写后的 `docs/upgrade_rollback_acceptance.md`。 | 备份、升级、迁移、健康检查、核心链路验证和回滚路径均演练通过。 |
| License Server 生产验证 | License Server 激活码、审计日志、备份文件和状态流转记录。 | 在线激活、刷新、续期、挂起、吊销、恢复、部署指纹复用拒绝、离线导入指纹不匹配拒绝均通过。 |
| 客户交付包确认 | 固定版本镜像、`.env.example`、升级脚本、License 验证脚本和发布说明。 | 部署包不使用 `latest`，不包含 License 私钥或内部 License Server 源码。 |
| 文档最终校对 | README、PRD、部署、运维、用户手册、发布说明、检查表。 | 引擎支持边界、权限码、截图、命令和 License 说明与当前代码一致。 |

## P1 交付增强

这些任务不阻断 v1.0-GA 首批客户交付，但应进入后续补丁或客户项目计划。

| 任务 | 交付物 | 验收口径 |
|---|---|---|
| 客户验证后交付引擎实测 | Oracle、MSSQL、Elasticsearch/OpenSearch、Doris 的客户同构环境验证记录。 | 每个启用引擎完成连接、元数据、在线查询、SQL 工单或审核边界、观测/活动采集和错误处理验证。 |
| 性能基线与容量建议 | Locust 或等价压测报告，含接口延迟、并发、Worker 队列和数据库容量建议。 | 给出客户规模对应的 CPU、内存、PostgreSQL、Redis、Worker 并发和保留周期建议。 |
| 前端包体持续优化 | 首轮已移除未使用的 `@ant-design/pro-components` 并取消集中 `ui-vendor` 打包；后续按页面继续观察包体。 | 生产构建不出现超过交付阈值的大 chunk 提醒；若后续新增重型依赖，需在发布说明中解释影响和处理计划。 |
| 自动化截图与冒烟 E2E | Playwright 或等价脚本。 | 用户手册截图可重复生成，核心页面冒烟测试在本地和 CI 可运行。 |

## P2 后续路线

这些任务属于后续商业化和平台增强，不进入当前 GA 发布闸门。

| 任务 | 交付物 | 验收口径 |
|---|---|---|
| Cassandra 引擎正式化 | 在当前最小兼容层基础上完成真实环境驱动验证、写执行边界、集成测试和客户交付文档。 | 通过客户同构环境验证后，才可从“待验证”调整为“客户验证后交付”或“正式支持”。 |
| 更深度的集成测试矩阵 | 多数据库真实服务、通知通道和归档场景集成测试。 | 覆盖正式支持引擎主链路和关键失败场景。 |

## 不再规划

以下 License 后续增强不进入当前产品路线，除非后续重新立项：

- License 套餐模板与用量可见性。
- License 运维监控增强。
- License 部署迁移生命周期。
- 多部署与商业报表。

## 当前注意事项

- 引擎支持边界以 `docs/engine_support_matrix.md` 为准，不得把“待验证”能力写入客户标准承诺。
- 客户现场真实创建工单、查询权限申请、归档作业、License 激活和通知投递时，必须显式开启验收脚本对应参数，并记录结果。
- 当前前端生产构建已消除 vendor 循环分包提示和大 chunk 提醒；最大 JS chunk 约 395KB，后续新增重型依赖时继续跟踪。
- 后端本地单元测试、前端测试、类型检查、Lint 和生产构建已通过；最终发布仍以 CI 结果为准。
