# SagittaDB 引擎支持矩阵

> 适用版本：v1.0-GA 商业交付线。该矩阵用于售前承诺、实施验收和用户手册口径统一。

## 支持等级

| 等级 | 含义 | 交付承诺 |
|---|---|---|
| 正式支持 | 已进入 v1.0-GA 核心交付范围。 | 可按标准部署、培训和验收流程交付。 |
| 客户验证后交付 | 已有最小可用实现，但需要客户同构环境确认。 | 售前和实施需明确验证范围，通过后再纳入客户项目交付。 |
| 待验证 | 已有适配入口或最小兼容层，但真实环境验证和交付边界尚未完成。 | 不作为 v1.0-GA 正式承诺，除非单独立项并完成真实环境验证。 |
| 暂不承诺 | 未纳入当前版本支持矩阵。 | 不进入交付范围。 |

| 数据库类型 | 支持等级 | 当前边界 |

| PostgreSQL | 正式支持 | 实例管理、Schema 注册、数据字典、在线查询、SQL 工单、归档和观测主链路。 |

| Redis | 正式支持 | 连接、数据库编号注册、白名单查询控制和基础观测能力。 |
| ClickHouse | 正式支持 | 连接、元数据、在线查询、SQL 工单、SQL 活动采集和观测主链路。 |
| StarRocks | 正式支持 | 连接、元数据、在线查询、SQL 工单和归档 purge 主链路。 |
| Oracle | 客户验证后交付 | 已有最小可用实现；需验证驱动模式、元数据、查询、工单和客户版本兼容性。 |

| Elasticsearch / OpenSearch | 客户验证后交付 | 已有最小可用实现；覆盖连接、索引元数据、SQL API 只读查询、任务活动采集和基础健康监控，需验证客户版本兼容性。 |

## goInception 边界

goInception 仅对 MySQL 审核有价值，不覆盖 SagittaDB 的多引擎产品目标。v1.0-GA 默认使用基于 sqlglot 的统一审核规则层；goInception 仅保留为 P3 Backlog 的 MySQL 专用可选适配器。

## 实施要求

- 客户项目中如需启用“客户验证后交付”引擎，应在测试环境完成连接、元数据同步、在线查询、SQL 工单、审计和回滚方案验证。
- “待验证”引擎不得在合同、方案或培训材料中作为标准功能承诺。
- 若客户明确要求某个“待验证”引擎，应单独立项，补充真实环境测试、引擎实现、文档和回归用例。

## 最新剩余计划任务

统一任务清单见 `docs/remaining_plan.md`。引擎相关研发兼容层已完成本地单测覆盖；剩余任务集中在“客户验证后交付”引擎实测和 Cassandra 真实环境验证，不改变当前 GA 支持承诺。
