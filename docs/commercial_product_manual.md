# SagittaDB Enterprise 产品使用手册

> 文档版本：v1.0  
> 适用产品：SagittaDB Enterprise 正式商业版 2.2.0  
> 目标读者：试用客户、研发工程师、DBA、系统管理员、运维工程师、安全审计员、实施顾问  
> 授权项目码：`sagittadb`

本文面向正式商业试用和客户培训场景，说明 SagittaDB Enterprise 的主要页面、典型流程和注意事项。实际页面可能因客户版本、角色权限、系统配置和授权状态略有差异。

## 1. 使用前准备

### 1.1 访问条件

使用 SagittaDB 前，请确认：

- 已获得平台访问地址。
- 已由管理员创建账号，或企业身份登录已完成配置。
- 已分配合适角色、用户组和资源范围。
- 如需查询数据，已获得对应实例、数据库或表级查询授权。
- 如需接收通知，已维护邮箱、钉钉、飞书或企业微信身份。

### 1.2 常见角色

| 角色 | 主要使用场景 |
|---|---|
| 研发工程师 | 提交 SQL 工单、申请查询权限、在线查询、查看数据字典。 |
| DBA | 管理实例、审批/执行工单、处理查询权限、诊断数据库运行状态、执行归档。 |
| 系统管理员 | 管理用户、角色、用户组、资源组、审批流、系统配置和 License。 |
| 运维工程师 | 部署维护平台、巡检服务、备份恢复、升级回滚、处理告警。 |
| 安全审计员 | 查看审计日志、查询历史、权限变更、高风险操作和合规报表。 |
| 实施顾问 | 完成客户现场初始化、试用演示、验收报告和正式推广门禁。 |

### 1.3 核心概念

| 概念 | 说明 |
|---|---|
| 角色 | 决定用户可以执行哪些功能操作。 |
| 用户组 | 将用户组织到业务、项目或团队范围内。 |
| 资源组 | 维护一组数据库实例，通常对应业务线、环境或项目。 |
| 查询权限 | 控制用户可以查询哪些实例、数据库或表。 |
| 审批流 | 控制 SQL 工单、查询权限申请、归档申请等流程的审核路径。 |
| License | 控制商业授权状态、功能模块、用户数和实例数额度。 |

## 2. 登录与个人中心

入口：登录页、右上角个人菜单。

### 2.1 登录

操作步骤：

1. 打开 SagittaDB 访问地址。
2. 选择账号密码、LDAP、CAS、OIDC、短信验证码、钉钉、飞书或企业微信等已启用的登录方式。
3. 输入凭据并登录。
4. 如系统提示默认密码、弱密码或密码过期，请先完成强制改密。
5. 登录成功后进入 Dashboard 或当前角色默认页面。

注意事项：

- 登录入口由系统配置控制，未启用的第三方入口不会展示。
- LDAP、CAS、OIDC 等企业认证失败时，请联系管理员检查系统配置和账号绑定。
- 开启 2FA 后，登录时需要输入动态验证码。
- 产品页面默认使用中文界面，日期选择器和日期范围选择器中的月份、星期、`今天`、`请选择日期`、`开始日期`、`结束日期` 等控件文案均按简体中文展示。

### 2.2 个人设置

操作步骤：

1. 点击右上角用户名。
2. 打开 `个人设置`。
3. 修改显示名称、邮箱等个人信息。
4. 按需开启或关闭二步验证。
5. 保存配置。

### 2.3 修改密码

操作步骤：

1. 点击右上角用户名。
2. 打开 `修改密码`。
3. 输入当前密码和新密码。
4. 保存后使用新密码重新登录。

密码建议：

- 至少 8 位。
- 包含数字、大写字母、小写字母和特殊字符。
- 不使用默认密码、姓名、手机号、生日或简单连续字符。

## 3. Dashboard

入口：侧边栏 `Dashboard`。

Dashboard 展示当前用户权限范围内的整体概览，包括：

- 在线查询概览。
- SQL 工单概览。
- 数据归档概览。
- 实例与数据库概览。
- 趋势图和 Top 排行。

使用建议：

- 研发可关注自己的查询和工单状态。
- DBA 可关注审批、执行、失败任务和实例状态。
- 管理员可关注平台初始化、授权状态和资源配置完整性。
- 审计员可从统计数据进入查询历史和审计日志进一步追踪。

注意事项：

- Dashboard 数据按当前用户权限裁剪，不同用户看到的数字可能不同。
- 如果看不到某个业务数据，优先检查角色权限、用户组、资源组和查询授权。

## 4. 实例管理

入口：侧边栏 `实例管理`。  
适用角色：DBA、系统管理员、实施顾问。

### 4.1 新建数据库实例

操作步骤：

1. 点击 `新建实例`。
2. 填写实例名称、数据库类型、主机、端口、用户名和密码。
3. 如需跳板机，填写 SSH 隧道配置。
4. 点击 `测试连接`。
5. 测试通过后保存。
6. 将实例加入合适资源组。

注意事项：

- 实例密码、SSH 密钥等敏感字段会加密存储。
- 生产环境接入前建议先使用只读或最小权限账号验证。
- 实例关联资源组后，普通用户只能通过用户组和资源组关系看到实例。
- 删除实例前需确认无资源组、工单、查询授权或归档作业依赖。

### 4.2 注册数据库或 Schema

操作步骤：

1. 打开实例详情或数据库管理区域。
2. 选择自动同步或手动添加数据库/Schema。
3. 检查同步结果。
4. 按需启用或停用数据库。

注意事项：

- 停用数据库后，普通用户不可提交工单或在线查询。
- 数据字典、在线查询和 SQL 工单都依赖注册数据库状态。
- PostgreSQL 和 Oracle 场景中，应关注 schema 命名和权限差异。

### 4.3 引擎支持边界

| 支持等级 | 数据库类型 | 使用说明 |
|---|---|---|
| 标准支持 | MySQL、TiDB、PostgreSQL、MongoDB、Redis、ClickHouse、StarRocks | 可按标准链路使用连接测试、查询、工单、字典和观测。 |
| 客户验证后交付 | Oracle、MSSQL、Elasticsearch、OpenSearch、Doris | 按项目验证结果交付；MSSQL、Elasticsearch、OpenSearch 和 Doris 已补齐观测专属适配，正式接入前需在客户同构环境验证权限、版本兼容和交付范围。 |
| 只读/元数据边界 | Cassandra/ScyllaDB | 支持连接、元数据、表 DDL、主键/索引元数据、只读 SELECT、基础健康、peer、容量估算和 compaction 历史；DDL/DML/BATCH 工单执行不纳入标准交付，深度运行指标需 JMX/sidecar。 |
| 定制评估 | 矩阵外数据库 | 需单独评估和实施。 |

## 5. SQL 工单

入口：侧边栏 `SQL 工单`。  
适用角色：研发工程师、DBA、审批人。

### 5.1 提交工单

操作步骤：

1. 进入 `SQL 工单`。
2. 点击提交工单。
3. 填写工单标题、目标实例和数据库。
4. 输入 SQL 内容。
5. 按需选择工单模板或使用 AI Text2SQL 辅助生成 SQL。
6. 查看风险提示。
7. 提交工单。

注意事项：

- 目标实例必须在当前用户资源范围内。
- 目标数据库必须处于启用状态。
- 高风险 SQL 可能需要更严格审批或额外权限。
- 工单创建后，审批流会生成快照，后续审批模板变更不影响当前工单。

### 5.2 查看工单

常用列表：

| 列表 | 用途 |
|---|---|
| 我的工单 | 查看自己提交的工单和执行结果。 |
| 审批记录 | 查看待我审批和我已处理的工单。 |
| 执行记录 | 查看待执行、执行中、执行完成或执行失败的工单。 |

### 5.3 审批工单

操作步骤：

1. 打开待审批工单详情。
2. 查看提交人、实例、数据库、SQL 内容和风险提示。
3. 点击审批通过或驳回。
4. 驳回时填写原因。

注意事项：

- 只有当前审批节点处理人可以审批。
- 审批意见会进入审计记录。
- 对高风险 SQL，建议结合业务窗口、备份状态和回滚方案后再审批。

### 5.4 执行工单

操作步骤：

1. 打开已审批通过的工单。
2. 确认目标实例、数据库和 SQL 内容。
3. 点击执行。
4. 查看异步执行进度、影响行数和错误信息。

注意事项：

- SQL 执行由后台任务处理。
- 执行失败时，优先查看数据库返回错误、连接状态和 Worker 日志。
- 生产环境执行 DDL/DML 前建议确认备份或回滚方案。

## 6. 在线查询

入口：侧边栏 `在线查询`。  
适用角色：研发工程师、DBA。

### 6.1 执行查询

操作步骤：

1. 选择实例。
2. 选择数据库或 Schema。
3. 在编辑器中输入 SQL。
4. 点击执行。
5. 查看结果、列信息、错误提示或脱敏展示。

查询前平台会依次检查：

- SQL 语法。
- SQL 基础语义。
- SQL 类型是否允许在线执行。
- 用户功能权限。
- 用户资源范围。
- 实例、库或表级查询授权。
- 数据库是否启用。

注意事项：

- 普通在线查询主要用于只读查询。
- 返回结果受最大行数限制。
- 命中脱敏规则的字段会显示脱敏后的值。
- 查询失败时，页面会尽量提示是语法、语义、权限、语句类型还是数据库状态问题。

### 6.2 查询历史

入口：侧边栏 `在线查询` 或 `查询历史`。

可查看内容：

- 执行人。
- 执行时间。
- 实例和数据库。
- SQL 内容。
- 返回行数。
- 是否导出。
- 是否脱敏。
- 成功或失败状态。

使用建议：

- 研发可复用历史查询。
- DBA 可排查查询失败和访问范围问题。
- 审计员可追踪敏感查询和导出行为。

## 7. 查询权限申请

入口：侧边栏 `查询权限`。  
适用角色：研发工程师、审批人、DBA。

### 7.1 提交申请

操作步骤：

1. 点击新建查询权限申请。
2. 选择目标实例。
3. 选择授权粒度：实例、数据库或表。
4. 设置有效期。
5. 填写申请原因。
6. 提交审批。

注意事项：

- 查询权限到期后自动失效。
- 数据字典可见范围继承查询权限。
- 不建议申请长期、过大范围的生产数据权限。

### 7.2 审批申请

操作步骤：

1. 打开查询权限审批列表。
2. 查看申请人、实例、授权范围、有效期和原因。
3. 选择通过或驳回。
4. 驳回时填写原因。

审批建议：

- 按最小权限原则授予。
- 对生产敏感库优先授予库级或表级权限。
- 对临时排障需求设置较短有效期。

## 8. 数据字典

入口：侧边栏 `数据字典`。  
适用角色：研发工程师、DBA。

操作步骤：

1. 选择实例。
2. 选择数据库或 Schema。
3. 选择表。
4. 查看字段、类型、约束、索引和 DDL。

注意事项：

- 数据字典可见范围继承查询权限。
- 如果看不到某张表，请先检查查询授权范围和数据库启用状态。
- PostgreSQL 跨 schema 同名表需注意 schema 前缀。

## 9. 数据脱敏

入口：侧边栏 `数据脱敏`。  
适用角色：DBA、系统管理员、安全审计员。

操作步骤：

1. 新建脱敏规则。
2. 设置规则名称、匹配范围和脱敏类型。
3. 选择内置规则或配置自定义正则。
4. 保存规则。
5. 使用在线查询验证脱敏结果。

建议优先覆盖：

- 手机号。
- 邮箱。
- 身份证号。
- 银行卡号。
- 地址。
- Token、密钥、凭据类字段。

注意事项：

- 脱敏影响在线查询结果展示，不改变目标数据库原始数据。
- 新规则上线前建议在测试库或低风险表验证。

## 10. 观测中心与 SQL 洞察

入口：侧边栏 `观测中心`。  
适用角色：DBA、运维工程师、系统管理员。

### 10.1 实例观测

可查看内容：

- 实例健康状态。
- 连接数、QPS/TPS、容量趋势等指标。
- 当前慢查询。
- 当前锁等待或阻塞会话。
- Top SQL。
- 数据库和表容量。
- 告警事件。
- Redis 专属指标：内存使用率、Ops/sec、缓存命中率、Key 淘汰、拒绝连接、复制角色和慢命令。
- ClickHouse 专属指标：当前查询、连接数、查询计数增量、失败查询、延迟/拒绝写入、内存使用、磁盘使用率和表容量。
- StarRocks 专属指标：FE/BE/CN、Load、Routine Load、Compaction、Tablet、资源组和当前 SQL 活动。
- Doris 专属指标：FE/BE、Load、Routine Load、Compaction、Tablet 和当前 SQL 活动。
- MSSQL 专属指标：waits、blocking、deadlock、tempdb、job、执行计划和缺失索引建议。
- MongoDB 专属指标：currentOp、profiler 慢操作、ReplicaSet/Sharding、WiredTiger、数据库和集合级容量。
- Elasticsearch 专属指标：通过独立 Elasticsearch 引擎和官方客户端采集 cluster/node/index/shard、heap、thread pool、segment 和任务活动。
- OpenSearch 专属指标：通过独立 OpenSearch 引擎、opensearch-py 客户端和 OpenSearch SQL 插件采集 cluster/node/index/shard、heap、thread pool、segment 和任务活动。
- Cassandra/ScyllaDB 专属指标：peer、容量估算和 compaction 历史；JMX/sidecar 未接入时会提示读写延迟、tombstone、SSTable、cache、thread pool 等深度指标边界。

注意事项：

- MySQL 当前慢查询表示当前正在执行且超过阈值的会话，不等同历史累计慢查询。
- 锁等待表示当前正在等待锁或被阻塞的会话。
- Redis 容量不按传统库表模型展示，重点关注内存、连接、命中率和 Key 淘汰。
- ClickHouse QPS/TPS 依赖相邻采集快照的系统事件计数差值，首次采集后可能需要等待下一次采集才出现速率。
- SQL 洞察依赖目标数据库权限和采集配置。

### 10.2 会话诊断

可执行操作：

- 查看当前会话列表。
- 查看历史会话采样。
- 查看等待事件、阻塞关系和长事务线索。
- 在有权限且确认风险后执行 Kill 会话。

注意事项：

- Kill 会话属于高风险操作，应确认业务影响。
- Oracle 诊断默认保持只读采集边界，不执行 trace dump、baseline、profile、patch 等变更类动作。

### 10.3 SQL 洞察

可查看内容：

- SQL 样本。
- SQL 指纹聚合。
- 执行计划。
- SQL 优化建议。
- 采集来源和采集状态。

使用建议：

- 先按实例、数据库、时间范围筛选。
- 再查看 Top SQL 和指纹聚合。
- 对高耗时 SQL 查看样本和执行计划。
- 对采集失败项检查目标数据库账号权限。

## 11. 数据归档

入口：侧边栏 `数据归档`。  
适用角色：研发工程师、DBA、审批人。

### 11.1 提交归档申请

操作步骤：

1. 新建归档申请。
2. 选择源实例、数据库和表。
3. 填写归档条件。
4. 配置批次大小和执行策略。
5. 提交审批。

注意事项：

- 归档条件必须经业务确认。
- 生产归档前建议完成备份。
- 涉及删除或迁移时，应明确回滚方案。

### 11.2 执行与管理归档作业

可执行操作：

- 查看作业状态。
- 启动作业。
- 暂停作业。
- 继续作业。
- 取消作业。
- 查看批次日志和影响行数。

## 12. 系统管理

入口：侧边栏 `系统管理`。  
适用角色：系统管理员。

### 12.1 用户管理

可执行操作：

- 创建、编辑、禁用用户。
- 分配角色。
- 设置直属上级、部门和职位。
- 维护邮箱、钉钉、飞书、企业微信等通知身份。
- 批量导入和导出用户。

### 12.2 角色管理

可执行操作：

- 查看内置角色。
- 创建业务角色。
- 分配权限码。
- 禁用或删除非系统角色。

建议：

- 不随意扩大超级管理员范围。
- 对审批、执行、归档、Kill 会话、系统配置等高风险权限单独管理。

### 12.3 用户组与资源组

推荐配置顺序：

1. 创建资源组并关联实例。
2. 创建用户组并关联资源组。
3. 将用户加入用户组。
4. 给用户分配角色。
5. 验证用户可见实例和可执行功能。

### 12.4 审批流

审批人类型：

| 类型 | 说明 |
|---|---|
| 指定用户 | 由固定人员审批。 |
| 直属上级 | 根据用户上级关系解析审批人。 |
| 任意审批员 | 具备审批权限的用户均可处理。 |

注意事项：

- 审批流变更只影响后续新建流程。
- 在途工单使用创建时的审批流快照。

### 12.5 系统配置

配置范围：

- 平台名称和 Logo。
- 登录方式：本地账号、LDAP、CAS、OIDC、短信验证码、钉钉、飞书、企业微信。
- 通知渠道：邮件、钉钉、飞书、企业微信。
- AI Text2SQL 模型配置。
- 查询默认限制和安全策略。

注意事项：

- 敏感配置会加密存储。
- 配置变更会进入审计日志。
- 第三方认证和通知建议在正式推广前完成连通性测试。

## 13. 审计与合规

入口：侧边栏 `审计日志`、`查询历史`、`商业交付` → `交付与支持`。

可追踪内容：

- 登录和登出。
- 用户、角色、用户组、资源组变更。
- 系统配置变更。
- SQL 工单提交、审批、执行和取消。
- 在线查询和导出。
- 查询权限申请、审批、撤销。
- 数据归档申请、审批、执行。
- License 激活、刷新和导入。
- 告警确认、静默和关闭。

使用建议：

- 安全审计员定期检查高风险操作和查询导出。
- 管理员定期检查长期有效查询权限。
- 交付和支持过程中使用脱敏诊断包，避免泄露密钥和连接串。

## 14. License 授权

入口：侧边栏 `商业交付` → `License 授权`。  
适用角色：系统管理员、实施顾问。

### 14.1 查看授权状态

页面可查看：

- License 状态。
- 授权项目：`SagittaDB（sagittadb）`。
- 客户 ID。
- 激活客户 ID。
- 部署指纹。
- 功能模块。
- 用户数和实例数额度。
- 到期时间和剩余天数。

标准授权功能模块：

```text
workflow, query, archive, monitor, ai, masking, instance
```

标准授权额度字段：

```text
max_users
max_instances
```

### 14.2 在线激活

操作步骤：

1. 在授权管理页输入正式客户 ID。
2. 复制正式激活部署指纹。
3. 商务或运营侧在 License-Server-Center 中创建 SagittaDB 激活码。
4. 将激活码交付给客户管理员。
5. 客户管理员输入激活码和客户 ID。
6. 点击在线激活。
7. 验证状态为正式授权。

注意事项：

- 授权项目码固定为 `sagittadb`，客户无需手动填写项目名。
- 在线授权默认需要至少每 7 天成功联网刷新一次。
- HTTP 试用环境可能限制剪贴板，页面会提供兼容复制方式。

### 14.3 联网刷新

在线授权成功后，可在授权页点击刷新 License。刷新会向授权中心提交当前客户、部署指纹和运行摘要，用于续期、状态校验和客户支持。

### 14.4 离线授权

适用于长期离线客户。

操作步骤：

1. 客户在授权管理页生成离线 Challenge。
2. 客户将 Challenge 文件发送给商务或支持团队。
3. 运营侧签发绑定部署指纹的 challenge-response 文件。
4. 客户在授权管理页导入 response 文件。
5. 系统校验签名、客户 ID、项目码和部署指纹。

注意事项：

- 生产环境默认不接受未绑定 Challenge 的裸 License JSON。
- 离线授权仍受到期时间、部署指纹和功能模块限制。

## 15. 商业交付与支持

入口：侧边栏 `商业交付` → `交付与支持`。  
适用角色：系统管理员、实施顾问、安全审计员。

可执行操作：

- 查看推广就绪度。
- 查看试用/授权状态。
- 查看客户 ID、正式激活部署指纹、活跃用户数和活跃实例数。
- 查看推广前待处理项。
- 初始化试用环境。
- 完成实施交付向导。
- 生成 Markdown 或 JSON 验收报告。
- 生成脱敏诊断包。
- 查看合规报表。
- 处理告警事件。
- 查看引擎支持矩阵。

推广就绪度：

| 状态 | 含义 |
|---|---|
| 可推广 | 核心授权、实例、治理、通知、验收和运行状态满足要求。 |
| 需补配置 | 可继续试用或演示，但建议补齐配置后再正式推广。 |
| 阻塞 | 存在正式推广前必须处理的问题。 |

注意事项：

- `初始化试用环境` 不会伪造活跃实例，也不会保存真实数据库密码。
- 正式推广前应生成验收报告并保留客户现场记录。
- 客户现场最终上线前应执行客户包中的 `go-live-check.sh`。

## 16. 常见问题

| 问题 | 处理建议 |
|---|---|
| 看不到某个实例 | 检查用户组、资源组、实例启用状态和角色权限。 |
| 能看到实例但不能查询 | 检查查询权限是否存在、是否过期、粒度是否匹配。 |
| 数据字典看不到表 | 数据字典继承查询权限，先确认查询授权范围。 |
| 工单不能提交 | 检查实例资源范围、数据库启用状态、SQL 风险和用户权限。 |
| 审批按钮不显示 | 当前用户不是当前审批节点处理人，或流程状态不允许审批。 |
| 查询结果被脱敏 | 命中了数据脱敏规则，这是平台安全策略。 |
| 通知没收到 | 检查用户通知身份、系统通知配置和通知投递日志。 |
| License 激活失败 | 检查客户 ID、激活码、部署指纹、授权项目和授权中心状态。 |
| 在线授权刷新失败 | 检查网络、授权服务器地址、授权中心状态和本地 License 状态。 |
| 试用到期无法使用业务功能 | 登录后进入授权管理页完成正式激活或导入离线授权。 |

## 17. 推荐试用路径

客户试用建议按以下顺序推进：

1. 完成平台部署和管理员初始化。
2. 进入 30 天全功能试用。
3. 创建首个数据库实例并测试连接。
4. 创建资源组、用户组、角色和审批流。
5. 创建普通研发账号并验证登录。
6. 提交查询权限申请并审批通过。
7. 执行在线查询并验证脱敏和查询历史。
8. 提交 SQL 工单并完成审批与执行。
9. 配置通知渠道并验证消息送达。
10. 配置观测采集并查看实例运行指标。
11. 按需验证数据归档。
12. 在商业交付页生成验收报告。
13. 获取正式激活码或离线授权。
14. 执行正式推广前 go-live 检查。
