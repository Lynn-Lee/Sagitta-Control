## 1. 品牌定位

SagittaDB 矢准数据是一款面向企业数据库治理场景的多引擎数据库管控平台。

它帮助企业把数据库访问、SQL 变更、查询授权、运行诊断、数据归档和审计追踪统一到一个安全、可控、可交付的工作台中，形成统一入口、权限收敛、流程审批、异步执行和全程审计的数据库治理体系。

品牌主张：

```text
SagittaDB 矢准数据
矢向数据，精准管控
```

一句话介绍：

```text
SagittaDB 是企业级多引擎数据库管控平台，覆盖数据库实例管理、SQL 工单、在线查询、数据脱敏、运行诊断、数据归档和审计合规，帮助企业建立安全、可追溯、可运维的数据库治理入口。
```

## 2. 市场痛点

很多企业已经拥有多套业务系统、多种数据库和不同团队的研发、DBA、运维、安全人员，但数据库访问和变更流程仍然停留在分散工具和人工协作阶段：

- 数据库账号分散在不同团队手中，难以统一授权、回收和审计。
- SQL 上线依赖聊天工具、工单系统和手工执行，流程割裂且风险难控。
- 研发需要临时查数，DBA 需要控制数据边界，安全团队需要留痕，三方诉求难以兼顾。
- MySQL、PostgreSQL、Oracle、MongoDB、Redis、ClickHouse、StarRocks 等多引擎并存，运维入口和能力口径不统一。
- 敏感数据查询、导出、权限变更和高风险操作缺乏完整追踪。
- 数据库问题发生后，实时会话、慢 SQL、锁等待、容量趋势、执行计划等诊断信息分散，定位效率低。
- 商业部署、授权、验收、升级、回滚和运维交接缺少标准化闭环。

SagittaDB 的目标不是再增加一个单点工具，而是把数据库治理链路收拢成一个企业可长期运行的产品体系。

## 3. 产品价值

### 3.1 安全治理

SagittaDB 通过角色权限、用户组、资源组、查询授权、数据脱敏、License 功能控制和操作审计，帮助企业把数据库访问边界收敛到平台内。

客户价值：

- 降低共享账号、长期高权限账号和线下执行带来的安全风险。
- 让数据库访问、查询、审批、执行、导出、配置变更都有记录可追。
- 通过数据脱敏减少研发排障过程中的敏感数据暴露。
- 通过最小权限模型，把“能登录平台”和“能访问数据”拆开管理。

### 3.2 效率提升

SagittaDB 把 SQL 工单、在线查询、查询权限申请、审批流、主动通知和 AI Text2SQL 辅助集中到同一平台，减少研发、DBA 和审批人之间的反复沟通。

客户价值：

- 研发可自助提交 SQL 工单、查询权限和归档申请。
- DBA 可在统一页面审核、执行、诊断和追踪。
- 审批流自动留痕，工单创建后快照审批节点，避免流程变更影响在途事项。
- Celery 异步执行高耗时任务，减少 Web 请求阻塞。
- 通知渠道支持邮件、钉钉、飞书、企业微信等企业协作方式。

### 3.3 多引擎统一

SagittaDB 面向多数据库环境设计，统一纳管实例、库表元数据、在线查询、工单、观测和归档能力。

标准支持与交付边界：

| 支持等级 | 数据库类型 | 商业推广口径 |
|---|---|---|
| 标准支持 | MySQL、TiDB、PostgreSQL、MongoDB、Redis、ClickHouse、StarRocks | 可按标准流程接入实例、测试连接、使用查询、工单、字典和观测主链路。 |
| 客户验证后交付 | Oracle、MSSQL、Elasticsearch、OpenSearch、Doris | 按项目验证结果交付；MSSQL、Elasticsearch、OpenSearch、Doris 已补齐观测专属适配，正式接入前需在客户同构环境完成权限和版本验证并明确交付范围。 |
| 只读/元数据边界 | Cassandra/ScyllaDB | 支持连接、元数据、只读 SELECT、基础健康、peer、容量估算和 compaction 历史；DDL/DML/BATCH 工单执行和深度运行指标不作为标准交付承诺，深度指标需接入 JMX/sidecar。 |
| 定制评估 | 矩阵外数据库 | 需单独评估连接、权限、元数据、查询、安全边界和运维可行性。 |

### 3.4 运维可见

SagittaDB 提供观测中心、会话诊断、SQL 洞察、容量采样、采集配置、告警事件和诊断包能力，帮助 DBA 和运维团队更快发现问题、定位问题和保留支持材料。

客户价值：

- 查看实例健康、会话、慢 SQL、锁等待、Top SQL、容量趋势和执行计划。
- Oracle 观测支持 RAC 友好的会话、等待事件、阻塞会话、长事务和 SQL Monitor/AWR/游标缓存降级链路。
- StarRocks/Doris 观测支持 FE/BE/CN、Load、Compaction、Tablet 和查询活动；MSSQL 观测支持 waits、blocking、deadlock、tempdb、job 和缺失索引建议。
- MongoDB 观测支持 currentOp、profiler 慢操作、ReplicaSet/Sharding、WiredTiger 和集合级指标；Elasticsearch 使用独立 Elasticsearch SQL API 和客户端观测 cluster/node/index/shard、heap、thread pool、segment 和任务活动；OpenSearch 使用独立 OpenSearch SQL 插件和 opensearch-py 客户端观测同类指标。
- Cassandra/ScyllaDB 观测支持 peer、容量估算和 compaction 历史；读写延迟、tombstone、SSTable、cache、thread pool 等深度指标需接入 JMX/sidecar。
- MySQL 慢查询和锁等待按实时运行态展示，避免把历史累计值误判为实时风险。
- 诊断包自动脱敏密码、Token、Secret 和连接串，便于支持流转。

## 4. 核心能力文案

### 4.1 SQL 工单

把 SQL 变更从线下沟通变成可审批、可执行、可审计的标准流程。

能力亮点：

- 支持 SQL 提交、风险检查、审批流快照、审批、执行、取消和结果追踪。
- 支持异步执行，避免长 SQL 阻塞页面操作。
- 支持执行日志、审批记录和主动通知。
- 支持工单模板复用，降低重复提交成本。
- 支持 AI Text2SQL 辅助生成 SQL，帮助非 DBA 用户更快表达查询和变更意图。

客户收益：

- 降低误执行、越权执行和无审批执行风险。
- 让研发、DBA、审批人围绕同一工单协作。
- 为审计和复盘保留完整链路记录。

### 4.2 在线查询

给研发和业务排障提供安全可控的查询入口。

能力亮点：

- 支持多引擎在线查询和最大返回行数治理。
- 查询前执行语法、语义、语句类型和权限检查。
- 支持实例、库、表三级查询授权。
- 支持查询历史、收藏、导出行为追踪。
- 查询结果自动应用数据脱敏规则。

客户收益：

- 研发可按授权范围自助查数。
- DBA 可减少临时开账号、临时执行 SQL 的运维负担。
- 安全团队可追踪“谁在何时查询了什么数据”。

### 4.3 权限治理

用分层权限体系把功能权限、资源范围和数据授权拆开管理。

能力亮点：

- 角色决定用户能做什么。
- 用户组和资源组决定用户能看到哪些实例。
- 查询权限决定用户能查询哪些数据。
- 内置超级管理员、DBA、资源组 DBA、研发用户等典型角色。
- 支持审批流、查询权限有效期和权限变更审计。

客户收益：

- 权限结构清晰，便于落地最小权限原则。
- 支持组织、项目、业务线等资源隔离。
- 权限到期自动失效，减少长期授权沉淀。

### 4.4 数据字典

让研发在授权范围内自助查看库表结构，减少反复询问 DBA。

能力亮点：

- 展示字段、类型、约束、索引和 DDL。
- 可见范围继承查询权限，不额外增加授权体系。
- 支持 PostgreSQL schema、Oracle schema、Redis 数据库编号等差异化展示。

客户收益：

- 降低研发理解表结构的沟通成本。
- 避免把数据字典能力开放给无授权用户。

### 4.5 数据脱敏

把敏感数据保护嵌入查询链路。

能力亮点：

- 支持内置脱敏类型和自定义正则规则。
- 查询结果返回前自动脱敏。
- 可对手机号、邮箱、身份证、密钥、地址等敏感字段设置规则。

客户收益：

- 平衡研发排障效率与数据安全。
- 降低敏感信息在截图、导出和协作中的扩散风险。

### 4.6 观测中心与 SQL 洞察

用统一视图查看实例运行状态、SQL 风险和诊断线索。

能力亮点：

- 查看实例健康、会话、锁等待、慢 SQL、Top SQL、容量趋势。
- 支持 SQL 指纹、SQL 样本、执行计划和优化诊断。
- 支持采集配置、保留策略和告警事件。
- Oracle 观测按权限自动降级，缺少 AWR 或 SQL Monitor 权限时仍保留可用数据。

客户收益：

- DBA 可快速定位慢查询、锁等待、容量增长和异常会话。
- 运维团队可获得平台内诊断材料和脱敏诊断包。

### 4.7 数据归档

把历史数据归档从手工脚本变为审批可控的作业流程。

能力亮点：

- 支持归档申请、审批、分批执行、暂停、继续、取消。
- 支持批次日志、影响行数和执行结果追踪。
- 归档操作纳入通知和审计。

客户收益：

- 降低历史数据清理和迁移的误操作风险。
- 让高风险归档动作有审批、有日志、有责任链。

### 4.8 商业交付与授权

让客户试用、上线、授权、验收和支持都有标准路径。

能力亮点：

- 固定版本 Docker/Helm 商业部署包。
- 60 天全功能试用。
- 在线激活、联网刷新、离线 challenge-response。
- 授权项目固定为 `SagittaDB（sagittadb）`。
- 授权功能模块为 `workflow`、`query`、`archive`、`monitor`、`ai`、`masking`、`instance`。
- 支持 `max_users` 和 `max_instances` 额度控制。
- 商业交付页提供推广就绪度、验收报告、诊断包和支持矩阵。

客户收益：

- 试用可快速启动，正式授权可平滑切换。
- 长期离线客户可通过 challenge-response 完成授权。
- 上线前可用脚本和页面双重验收，降低交付风险。

## 5. 典型场景

### 5.1 研发自助查询与权限申请

研发需要排查线上问题，但不能长期持有生产库账号。通过 SagittaDB，研发先提交查询权限申请，审批通过后在授权范围内在线查询，查询结果按脱敏规则展示，查询历史自动留痕。

推广话术：

```text
SagittaDB 让研发可以安全自助查数，同时让 DBA 和安全团队保留权限边界、脱敏规则和审计记录。
```

### 5.2 SQL 上线审批与执行

业务变更需要执行 DDL 或 DML。研发提交 SQL 工单，系统提示风险，审批人逐级审核，DBA 在维护窗口执行，执行结果和日志自动回写。

推广话术：

```text
SagittaDB 把 SQL 上线变成标准化流程，审批、执行、通知、日志和审计都在同一个闭环内完成。
```

### 5.3 多数据库统一管控

企业同时使用 MySQL、PostgreSQL、Oracle、MongoDB、Redis、ClickHouse、StarRocks 等数据库。SagittaDB 提供统一实例管理、查询、字典、工单和观测入口，让不同数据库的治理体验尽量一致。

推广话术：

```text
SagittaDB 不是只面向单一数据库的工具，而是为企业多引擎数据库治理准备的统一入口。
```

### 5.4 DBA 运行诊断

数据库出现性能波动，DBA 在观测中心查看当前会话、慢 SQL、锁等待、容量趋势和 Top SQL，必要时导出脱敏诊断包给支持团队。

推广话术：

```text
SagittaDB 把数据库运行态线索放到平台里，让 DBA 不必在多个工具和命令之间来回切换。
```

### 5.5 合规审计

安全审计员需要追踪一段时间内的用户登录、查询、导出、权限变更和高风险操作。SagittaDB 提供操作审计、查询历史、通知日志和合规报表，辅助审计复盘。

推广话术：

```text
SagittaDB 让数据库使用链路有据可查，帮助企业建立可追溯、可复盘的治理机制。
```

## 9. 客户决策 FAQ

### SagittaDB 适合什么客户？

适合同时具备以下一种或多种诉求的企业：

- 需要规范 SQL 上线审批和执行。
- 需要让研发安全地在线查询生产或准生产数据。
- 需要统一管理多种数据库实例。
- 需要数据库访问审计、查询历史和敏感数据脱敏。
- 需要 DBA 统一查看会话、慢 SQL、锁等待、容量和运行诊断信息。
- 需要可私有化部署、可授权、可验收、可升级的商业交付方案。

### SagittaDB 是否替代现有数据库？

不替代。SagittaDB 是数据库管控平台，连接和治理客户已有数据库，不改变客户业务系统访问数据库的主链路。

### SagittaDB 是否需要公网？

平台本身可以部署在客户内网。在线授权默认需要访问 License-Server-Center 并至少每 7 天成功刷新一次。长期离线客户可以使用 challenge-response 离线授权。

### SagittaDB 能否对接企业身份系统？

可以。SagittaDB 支持本地账号，也支持 LDAP、OIDC、CAS、短信验证码、钉钉、飞书、企业微信等登录或通知配置，具体以客户现场认证方案为准。

### 商业授权控制哪些内容？

SagittaDB 商业授权功能模块包括：

```text
workflow, query, archive, monitor, ai, masking, instance
```

授权还支持用户数和实例数额度控制：

```text
max_users
max_instances
```

### 试用到期会怎样？

首次部署默认进入 60 天全功能试用。试用到期后，业务 API 会被阻断，登录、健康检查和授权管理入口仍可访问，管理员可以完成正式激活或导入离线授权。

- 试用策略：60 天全功能试用。
