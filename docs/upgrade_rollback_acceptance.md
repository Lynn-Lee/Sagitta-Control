# SagittaDB 升级回滚验收表

> 用于商业交付升级窗口。升级前由实施人员填写，升级后由客户或项目负责人确认。

## 1. 升级前确认

| 检查项 | 要求 | 结果 |
|---|---|---|
| 升级版本 | 已确认目标版本和镜像标签。 |  |
| 发布说明 | 已阅读目标版本发布说明。 |  |
| 维护窗口 | 已确认升级时间、联系人和回滚决策人。 |  |
| 数据库备份 | 已完成 PostgreSQL 元数据库备份。 |  |
| 配置备份 | 已备份 `.env`、Compose/Helm 配置和客户自定义文件。 |  |
| 当前版本记录 | 已记录当前 Git SHA、镜像标签和 Alembic revision。 |  |
| License 状态 | 当前 License 有效，部署指纹已记录。 |  |

## 2. 升级执行

| 步骤 | 命令或动作 | 结果 |
|---|---|---|
| 停止写入窗口 | 通知用户暂停工单执行和归档作业。 |  |
| 拉取新版本 | 拉取目标版本代码或镜像。 |  |
| 执行迁移 | `alembic upgrade head` 或 initContainer 自动迁移。 |  |
| 重启服务 | 重启 frontend、backend、worker、beat。 |  |
| 预检脚本 | 运行 `deploy/preflight-check.sh`。 |  |

## 3. 升级后验收

| 检查项 | 要求 | 结果 |
|---|---|---|
| Web 访问 | 前端可访问，静态资源加载正常。 |  |
| 后端健康 | `/health` 返回 200。 |  |
| 登录 | 管理员和普通用户可登录。 |  |
| 权限 | 菜单和接口权限符合角色配置。 |  |
| 实例连接 | 至少一个正式支持引擎实例连接测试通过。 |  |
| SQL 工单 | 可提交、审批并执行一条测试工单。 |  |
| 查询权限 | 可申请、审批并在线查询。 |  |
| 数据字典 | 可查看表、字段、约束、索引和 DDL。 |  |
| 归档 | 可完成一次估算或测试归档流程。 |  |
| 通知 | 通知投递日志有记录，失败原因可见。 |  |
| License | 授权状态正常，可刷新或显示明确原因。 |  |
| 审计 | 操作审计和查询历史可查询。 |  |

## 4. 回滚方案

优先使用升级前备份恢复。只有迁移明确支持 downgrade 且已验证时，才允许执行 Alembic downgrade。

| 回滚条件 | 处理方式 | 决策人 |
|---|---|---|
| 服务无法启动 | 恢复上一版本镜像和配置，恢复数据库备份。 |  |
| 迁移失败 | 停止升级，恢复数据库备份。 |  |
| 核心链路不可用 | 评估是否热修；无法在窗口内修复则回滚。 |  |
| License 校验异常 | 检查公钥、部署指纹和 License Server；必要时回滚配置。 |  |
