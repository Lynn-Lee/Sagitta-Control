# Pack B 功能测试文档 — 观测中心

> **测试版本：** SagittaDB v1.0-GA + 观测中心 2 期
> **对应计划：** Pack B (Sprint 5+6) + 观测中心 2 期 — Dashboard 统计、实例运行态诊断、健康评分、TopN 诊断、阈值告警规则
> **测试环境：** http://localhost（前端）/ http://localhost:9090（Prometheus）/ http://localhost:3000（Grafana）
> **前置条件：** Pack A 测试通过，有若干历史工单数据
> **测试账号：** admin / Admin@2024!（默认密码会触发强制改密）；Grafana: admin / admin

---

## 测试范围

| 模块 | 覆盖内容 |
|---|---|
| Dashboard | 在线查询概览卡片、查询趋势、查询用户 Top 10、治理趋势、待审批库存趋势；SQL 工单概览卡片、趋势、排行图、按权限范围裁剪；实例与库概览卡片、实例类型/状态分布、库-Schema 状态分布 |
| 观测中心 | 舰队总览、实例诊断工作台、健康评分、会话洞察、SQL 洞察、真实区间 QPS/TPS、Top SQL、等待事件、容量增长、引擎专属指标包 |
| 监控配置 | 原生采集配置、采集诊断、实例级阈值告警规则；Prometheus Exporter 字段仅作为历史兼容 |
| Prometheus | 服务发现端点、指标采集 |
| Grafana | 面板加载、Dashboard 导入 |
| Alertmanager | 告警配置验证 |
| 会话诊断 | 在线连接清单、Kill 会话、平台历史会话快照、Oracle ASH/AWR 活跃采样 |
| SQL 洞察 | SQL 样本、SQL 指纹、指纹详情、采集配置、执行计划分析 |
