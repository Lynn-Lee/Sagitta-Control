# SagittaDB 安全配置清单

> 用于生产上线前安全复核。所有“必须”项未完成时，不建议进入正式生产。

## 1. 密钥与凭据

| 检查项 | 级别 | 要求 | 结果 |
|---|---|---|---|
| `SECRET_KEY` | 必须 | 已替换默认值，长度不少于 32 字符，并纳入客户密钥保管。 |  |
| PostgreSQL 密码 | 必须 | 不使用默认密码，权限仅限 SagittaDB 元数据库。 |  |
| Redis 密码 | 必须 | 不使用默认密码，未向公网暴露。 |  |
| Grafana 管理员密码 | 必须 | 不使用默认密码。 |  |
| License 公钥 | 必须 | `LICENSE_PUBLIC_KEY` 与内部 License Server 私钥匹配。 |  |
| License 部署 ID | 必须 | `LICENSE_DEPLOYMENT_ID` 已固定，升级不变更。 |  |
| 第三方密钥 | 必须 | LDAP/OAuth/通知/API Key 不写入代码仓库，不出现在日志中。 |  |

## 2. 网络暴露

| 检查项 | 级别 | 要求 | 结果 |
|---|---|---|---|
| Web 入口 | 必须 | 生产使用 HTTPS 或客户内网可信入口。 |  |
| PostgreSQL | 必须 | 不向公网暴露。 |  |
| Redis | 必须 | 不向公网暴露。 |  |
| Flower | 必须 | 不向公网暴露；如需开放，仅限内网和强认证。 |  |
| Prometheus / Grafana | 必须 | 不向公网裸露；Grafana 使用强密码。 |  |
| Swagger `/docs` | 建议 | 生产关闭或仅内网临时开放。 |  |

## 3. 账号与权限

| 检查项 | 级别 | 要求 | 结果 |
|---|---|---|---|
| 默认管理员 | 必须 | 初始化后立即修改密码。 |  |
| 超管账号 | 必须 | 数量最小化，至少登记责任人。 |  |
| 角色权限 | 必须 | DBA、研发、安全审计、系统管理职责分离。 |  |
| 用户组资源范围 | 必须 | 用户组仅绑定必要资源组。 |  |
| 查询权限有效期 | 必须 | 查询权限必须有有效期，不授予长期无边界权限。 |  |
| 离职账号 | 必须 | 已禁用或删除。 |  |

## 4. 数据与审计

| 检查项 | 级别 | 要求 | 结果 |
|---|---|---|---|
| 备份 | 必须 | 上线前完成一次备份与恢复演练。 |  |
| 审计日志 | 必须 | 操作审计、查询历史、通知投递日志可查询。 |  |
| 脱敏规则 | 建议 | 涉及敏感数据的库表已配置脱敏规则。 |  |
| 日志脱敏 | 必须 | 日志中不输出数据库密码、SSH 私钥、License 私钥或 API Key。 |  |
| 告警 | 建议 | 已接入客户侧监控或保留 Prometheus/Grafana 访问路径。 |  |

## 5. 发布前确认

- 已运行部署前预检脚本：`deploy/preflight-check.sh`。
- 已按 `docs/customer_initialization_checklist.md` 完成客户环境初始化。
- 已确认引擎支持范围符合 `docs/engine_support_matrix.md`。
- 已完成升级回滚验收，见 `docs/upgrade_rollback_acceptance.md`。

## 6. 最新剩余计划任务

统一任务清单见 `docs/remaining_plan.md`。安全相关剩余任务重点是全量安全流水线确认、License 私钥隔离复核、日志脱敏检查和外部入口暴露面复核；License Server 告警增强不再作为后续研发任务。
