# SagittaDB 用户使用手册

> 文档版本：v2.1
> 适用版本：SagittaDB v2.1 商业部署版 + v2-lite 授权体系
> 目标读者：研发工程师、DBA、系统管理员、安全审计员

本文截图来自演示环境，实际页面可能因版本、角色权限和客户配置略有差异。

## 1. 使用前准备

用户需要由系统管理员创建账号并分配角色、用户组和资源范围。若使用 LDAP、钉钉、飞书、企业微信或 CAS 登录，请确认企业身份已完成绑定。

常见角色：

| 角色 | 常见入口 |
|---|---|
| 研发工程师 | Dashboard、SQL 工单、在线查询、查询权限、数据字典。 |
| DBA | 工单审批/执行、实例管理、观测诊断、数据归档、权限审批。 |
| 系统管理员 | 用户、角色、用户组、资源组、审批流、系统配置。 |
| 安全审计员 | 审计日志、查询历史、通知投递日志。 |

## 2. 登录与个人设置

适用角色：所有用户
入口路径：登录页、右上角个人中心

操作步骤：

1. 打开 SagittaDB 访问地址。
2. 使用账号密码或第三方登录方式登录；第三方登录入口以图标展示，鼠标悬停可查看“使用 XXX 登录”提示，其中 `LDAP`、`CAS` 保持大写，钉钉、飞书和企业微信使用中文名称。
3. 如果系统提示默认密码、弱密码或密码过期，按提示修改密码。
4. 登录后进入 Dashboard。
5. 点击右上角用户名，在个人菜单中按需打开 `个人设置` 或 `修改密码`。
6. `个人设置` 弹窗用于修改显示名称、邮箱并管理二步验证（2FA）；`修改密码` 弹窗仅用于更新当前密码。

注意事项：

- 密码必须至少 8 位，并包含数字、大写字母、小写字母和特殊字符。
- 默认密码或过期密码只能获得短效改密令牌，必须改密后重新登录。
- 个人设置和修改密码是两个独立入口；修改账号信息不会影响当前密码，修改密码后下次登录需使用新密码。
- 系统弹窗、抽屉和确认框不会因点击外部遮罩区域关闭；需要点击弹窗内的取消、关闭或返回按钮退出。
- 全站常规按钮均采用统一高度和图标 + 文字样式；登录页第三方登录入口、返回按钮等紧凑控件可仅显示图标，并通过悬停提示说明操作。不同操作按功能使用统一颜色层级，便于区分主操作、查看/管理、编辑、导入导出、中性操作和危险操作。
- 个人设置弹窗采用左右分区布局，功能区边框与弹窗标题区对齐；小屏下自动上下排列，避免出现横向滚动。
- 开启 2FA 后，登录时需要额外输入 Google Authenticator、Authy 或兼容 TOTP 认证器中的动态验证码。
- 如果连续登录失败，请联系管理员检查账号状态或认证配置。

常见问题：

| 问题 | 处理方式 |
|---|---|
| 登录后要求改密 | 按页面提示设置符合复杂度要求的新密码。 |
| 需要修改显示名称或邮箱 | 点击右上角用户名，进入 `个人设置` 弹窗保存个人信息。 |
| 需要开启或关闭 2FA | 点击右上角用户名，进入 `个人设置` 弹窗，在二步验证区域操作。 |
| 需要主动修改密码 | 点击右上角用户名，进入 `修改密码` 弹窗，输入当前密码和新密码。 |
| 第三方登录失败 | 页面会按认证方式显示中文错误提示，例如 `飞书 登录未启用，请在系统配置中开启`；请联系管理员检查 OAuth/LDAP 配置和账号绑定。 |
| 页面提示无权限 | 联系管理员检查角色、用户组和资源组配置。 |

## 3. Dashboard

适用角色：所有用户
入口路径：侧边栏 `Dashboard`

Dashboard 展示当前登录用户权限范围内的统计信息，包括：

- 在线查询概览。
- SQL 工单概览。
- 实例与数据库/Schema 概览。
- 近期趋势和 Top 排行。

注意事项：

- 统计结果按用户权限范围裁剪，不同用户看到的数据可能不同。
- 审批统计反映当前权限范围内业务对象涉及的审批处理，不等同于个人工作量。

## 4. 实例与数据库注册

适用角色：DBA、系统管理员
入口路径：侧边栏 `实例管理`

### 4.0 引擎支持边界

| 支持等级 | 数据库类型 | 用户侧说明 |
|---|---|---|
| 正式支持 | MySQL、TiDB、PostgreSQL、MongoDB、Redis、ClickHouse、StarRocks | 可按标准流程创建实例、测试连接并进入数据字典、查询、工单和观测等主链路。 |
| 客户验证后交付 | Oracle、MSSQL、Elasticsearch/OpenSearch、Doris、Cassandra/ScyllaDB | 已有最小可用能力；MSSQL、Elasticsearch/OpenSearch、Doris 已补齐 SQL/任务活动或基础观测兼容层。Cassandra/ScyllaDB 支持连接、元数据、表 DDL、主键/索引元数据、只读 SELECT 和基础健康/版本/集群标识，DDL/DML/BATCH 工单执行关闭。正式接入前需由实施人员在客户同构环境完成验证。 |
| 待验证 | 矩阵外新增引擎 | 页面会显示“待验证”提示；不作为标准交付能力承诺。 |

如果客户项目需要矩阵外或“待验证”引擎，应单独立项评估，并在客户同构环境完成连接、元数据、查询、安全边界和运维验证。

### 4.1 新建实例

操作步骤：

1. 点击 `新建实例`。
2. 填写实例名称、数据库类型、主机、端口、账号、密码等连接信息。
3. 如需跳板机，配置 SSH 隧道。
4. 点击 `测试连接`。
5. 测试通过后保存。
6. 在资源组管理中将实例关联到合适资源组。

注意事项：

- 实例密码会加密存储。
- 实例仍被资源组关联时不能直接删除。
- Oracle 11g 需要后端启用 Thick 模式并提供 Instant Client；v2.1 起 Oracle 观测中心兼容 11g 动态性能视图差异。
- 新建、编辑和删除实例时，弹窗按钮、确认提示和必填校验提示均使用中文文案；必填项未填写时会提示 `请输入实例名称`、`请选择数据库类型`、`请输入主机地址`、`请输入端口` 或 `请输入用户名`。

### 4.2 注册数据库或 Schema

操作步骤：

1. 进入实例详情或数据库管理区域。
2. 选择 `从实例自动同步` 或手动添加。
3. 检查同步出的数据库/Schema 列表。
4. 按需启用或停用数据库。

注意事项：

- 停用数据库后，普通用户无法提交工单或在线查询。
- 管理员仍可看到停用数据库，并显示已禁用标识。
- Oracle 显示为 Schema，Redis 显示为数据库编号。

## 5. SQL 工单

适用角色：研发工程师、DBA
入口路径：侧边栏 `SQL 工单`

### 5.1 提交 SQL 工单

操作步骤：

1. 进入 `SQL 工单`，点击提交工单。
2. 填写工单名称。
3. 选择目标实例和数据库。
4. 在 SQL 编辑器中填写 SQL。
5. 按需选择工单模板或使用 AI Text2SQL 辅助生成。
6. 提交工单。

注意事项：

- 系统会自动按用户组、资源组和实例关系解析工单资源范围。
- 如果目标实例不在权限范围内，提交会被拒绝。
- 高风险 SQL 可能需要更严格审批或额外权限。

### 5.2 查看工单列表

列表视角：

| 标签 | 用途 |
|---|---|
| 我的工单 | 查看自己提交的工单。 |
| 审批记录 | 查看待我审批和我审批过的工单。 |
| 执行记录 | 查看进入执行阶段的工单。 |

### 5.3 审批工单

适用角色：审批人、DBA

操作步骤：

1. 打开待审批工单详情。
2. 查看 SQL 内容、目标实例、数据库、提交人和风险提示。
3. 点击 `审批通过` 或 `驳回`。
4. 驳回时填写原因。

注意事项：

- 只有当前审批节点审批人可以看到审批按钮。
- 审批流在工单创建时已快照，模板后续变更不影响当前工单。

### 5.4 执行工单

适用角色：DBA、具备执行权限的用户

操作步骤：

1. 打开已审批通过的工单。
2. 确认执行窗口和 SQL 内容。
3. 点击执行。
4. 查看执行进度和结果。

注意事项：

- SQL 执行由异步任务处理。
- 执行失败时查看执行日志和目标数据库错误信息。

## 6. 在线查询

适用角色：研发工程师、DBA
入口路径：侧边栏 `在线查询`

操作步骤：

1. 选择实例和数据库。
2. 在左侧浏览表结构。
3. 在 SQL 编辑器中输入查询语句。
4. 点击执行。
5. 在结果区域查看查询结果或错误提示。
6. 按需复制 DDL 或查看结果。

注意事项：

- 用户必须具备在线查询权限、实例资源范围和有效查询授权。
- 系统会先检查 SQL 语法和基础语义，再判断语句类型是否允许在线执行。
- 查询结果可能被最大返回行数限制。
- 命中脱敏规则的字段会显示脱敏后的值。
- 查询失败或被拒绝时，按提示检查 SQL 语法、SQL 语义、语句类型、权限或数据库状态。

## 7. 查询权限申请

适用角色：研发工程师、审批人
入口路径：侧边栏 `查询权限`

### 7.1 提交申请

操作步骤：

1. 进入查询权限页面。
2. 点击新建申请。
3. 选择实例、数据库和授权粒度。
4. 设置有效期并填写申请原因。
5. 提交申请。

注意事项：

- 授权粒度支持实例、数据库、表。
- 有效期到期后权限自动失效。
- 查询权限通过后，数据字典可见范围同步生效。

### 7.2 审批申请

操作步骤：

1. 进入查询权限审批列表。
2. 查看申请人、范围、有效期和原因。
3. 选择通过或驳回。
4. 驳回时填写原因。

## 8. 数据字典

适用角色：研发工程师、DBA
入口路径：侧边栏 `数据字典`

操作步骤：

1. 选择实例和数据库。
2. 选择表。
3. 查看字段列表、约束详情、索引信息。
4. 查看或复制 DDL。

注意事项：

- 数据字典可见范围继承查询权限。
- 禁用数据库对普通用户不可见。
- PostgreSQL 如存在跨 schema 同名表，需使用 `schema.table_name` 区分。

## 9. 数据脱敏

适用角色：DBA、系统管理员、安全审计员
入口路径：侧边栏 `数据脱敏`

操作步骤：

1. 进入脱敏规则页面。
2. 新增规则，选择匹配范围和脱敏类型。
3. 保存规则。
4. 使用在线查询验证脱敏结果。

注意事项：

- 脱敏规则会影响在线查询结果展示。
- 建议优先对手机号、邮箱、身份证、密钥、地址等字段设置规则。

## 10. 观测诊断

适用角色：DBA、运维工程师
入口路径：侧边栏 `观测中心`、`SQL 洞察`、`运行诊断`

常用功能：

- 查看实例健康和指标。
- 查看在线会话，必要时 Kill 会话。
- 查看历史会话采样。
- 查看 SQL 样本、SQL 指纹和实时 SQL。
- 对 MySQL/PostgreSQL 执行计划进行分析。
- 配置采集周期、阈值和保留策略。

注意事项：

- 实例概览中的 MySQL `当前慢查询` 为当前正在执行且超过 `long_query_time` 的会话数，`锁等待会话` 为当前等待锁或被阻塞的会话数，不代表历史累计值。
- 性能趋势中的 `本次慢查询` 表示相邻两次采集之间新增的慢查询次数，旧版累计快照会在接口侧自动换算成单次采集增量。
- StarRocks 的 Top SQL 来自 `SHOW PROCESSLIST` 可见的当前 SQL 活动；若账号缺少查看会话权限，页面会提示采集受限。
- Oracle 会话监控会优先展示 RAC 实例、OS PID、module/action、等待分类、阻塞实例和 PGA 信息；Top SQL 优先来自 SQL Monitor，并在 AWR 或 SQL Monitor 权限不足时自动降级到游标缓存或当前会话 SQL。
- Kill 会话属于高风险操作，应确认业务影响后执行。
- SQL 洞察数据依赖采集配置和目标数据库权限。

## 11. 数据归档

适用角色：研发工程师、DBA
入口路径：侧边栏 `数据归档`

操作步骤：

1. 新建归档申请。
2. 选择源实例、数据库、表和归档条件。
3. 配置归档模式和批次参数。
4. 提交审批。
5. 审批通过后由具备执行权限的用户执行。
6. 查看批次日志和执行结果。

注意事项：

- 归档条件必须经过业务确认，避免误删或误迁移。
- 执行前建议确认目标表、备份和回滚方案。
- 归档执行中可暂停、继续或取消。

## 12. 系统管理

适用角色：系统管理员
入口路径：侧边栏 `系统管理`

### 12.1 用户管理

可执行操作：

- 创建、编辑、禁用用户。
- 分配角色。
- 维护直属上级、部门、职位。
- 维护通知身份：邮箱、钉钉、飞书、企业微信。
- 批量导入导出用户。

### 12.2 角色管理

可执行操作：

- 查看内置角色。
- 创建业务角色。
- 为角色分配权限码。
- 禁用或删除非系统角色。

### 12.3 用户组与资源组

配置顺序建议：

1. 创建资源组并关联实例。
2. 创建用户组并关联资源组。
3. 将用户加入用户组。
4. 验证用户可见实例范围。

注意事项：

- 停用资源组不能被新关联。
- 实例仍被资源组关联时不能删除。

### 12.4 审批流管理

审批人类型：

| 类型 | 说明 |
|---|---|
| 指定用户 | 固定一个或多个审批人。 |
| 直属上级 | 使用用户 `manager_id` 解析审批人。 |
| 任意审批员 | 具备审批权限的用户均可处理。 |

### 12.5 系统配置

系统配置包括：

- 基础设置：平台名称、平台 Logo、平台访问地址、SQL 审核和查询默认限制。
- LDAP、钉钉、飞书、企业微信、CAS 登录。
- 邮件、钉钉、飞书、企微通知。
- AI Text2SQL API Key。
- 安全策略和其他运行时配置。

敏感配置会加密存储，修改后通常无需重启服务。

品牌设置说明：

- `平台名称` 会显示在登录页、顶部导航和浏览器标题中。
- `平台 Logo URL` 支持图片 URL，也支持上传 PNG/JPG/SVG/WebP 后自动保存为 data URL；留空时使用默认 Logo。
- 保存后刷新页面即可看到登录页、顶部导航、浏览器标题和 favicon 的品牌变化。前端会在应用启动前预加载品牌配置，避免浏览器刷新时短暂显示默认旧标题。
- 登录页底部版权文案显示为 `Copyright © 2026 Lynn-Lee. All rights reserved.`。

## 13. 审计日志

适用角色：安全审计员、系统管理员
入口路径：侧边栏 `审计日志`

可查看内容：

- 登录和退出。
- 用户、角色、资源、配置变更。
- 工单审批和执行。
- 查询权限申请和审批。
- 数据归档操作。

注意事项：

- 审计日志用于追溯，不建议普通用户开放。
- 查询历史用于追踪 SQL 执行和导出行为。

## 14. 授权管理

适用角色：系统管理员

入口路径：侧边栏 `系统管理` → `授权管理`

可执行操作：

- 查看当前 License 状态、授权项目、客户 ID、激活客户 ID、套餐、到期时间和部署指纹。
- 在线激活授权码。
- 输入客户 ID 后预览并复制正式激活部署指纹，用于在用户授权中心生成对应激活码。
- 刷新在线 License。
- 生成离线 Challenge，并导入商务/运营侧返回的 challenge-response License。
- 查看功能开关和限额信息。

注意事项：

- 授权项目固定显示为 `SagittaDB（sagittadb）`。在线激活和联网刷新时，系统会自动向 License-Server-Center 提交项目码 `sagittadb`，无需人工输入。
- 部署指纹用于绑定客户部署。在线激活区域输入客户 ID 后，页面会按该客户 ID 计算“正式激活部署指纹”；应使用该指纹在用户授权中心生成正式激活码。
- 复制部署指纹时，HTTPS 环境优先调用浏览器剪贴板能力；HTTP 试用部署会自动使用兼容复制方式，复制失败时页面仍会保留完整指纹供手动选择。
- 在线和离线 License 都必须通过 `LICENSE_PUBLIC_KEY` 完成 Ed25519 签名校验；未配置公钥时会提示“未配置 License 公钥”。
- 生产环境默认不接受未绑定 Challenge 的裸 License JSON。离线授权需先生成 Challenge，再导入包含 `challenge` 与 `license` 的响应文件。
- License 仅在签名、公钥、客户 ID、授权项目和部署指纹匹配时生效。
- License 异常时，受保护 API 会被阻断，授权管理页仍可访问。

## 15. 常见问题

| 问题 | 说明 |
|---|---|
| 为什么看不到某个实例？ | 用户组未关联包含该实例的资源组，或实例/数据库已停用。 |
| 为什么能看到实例但不能查询？ | 还需要有效的查询权限，或查询权限粒度不匹配。 |
| 为什么数据字典看不到表？ | 数据字典继承查询权限，需要先获得对应实例、库或表的查询授权。 |
| 为什么审批按钮不显示？ | 当前用户不是当前审批节点审批人，或工单状态不允许审批。 |
| 为什么通知没有收到？ | 用户通知身份未维护，或系统通知配置异常。 |
| 为什么执行失败？ | 查看工单执行日志，通常与 SQL 语法、目标数据库权限、连接或锁等待有关。 |
